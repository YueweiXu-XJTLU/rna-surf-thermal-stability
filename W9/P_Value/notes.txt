# P Value

- 从0.6s后开始：确保氢键已稳定

- 按时间分块取值（100ps一块）
    - 因为MD对于时间自相关，影响检验说服力
    - “前一帧刚走过的路还没散去”，下一帧会“跟着走”，信息重复。把若干连续帧合成一块→相当于“隔一段时间才记一次账”，重复信息被压缩，样本更接近独立

- Welch t 检验
    -分布层面（左图）
        - x小提琴表示分布情况
        - 黑点为组均值：300K ≈ 19.70；360K ≈ 14.49
        - 两组间差值明显，无重合；两组内部离散度相近，但相对组间均值差都不大 -- 组间差远大于组内波动
    - 效应量与不确定性（右图）
        - 均值差Δ ≈ 5.21。
        - 95% CI = [4.75, 5.67] 完全在 0 之上 -- 差异稳定、方向明确（300K 更高）
        - t=22.42，df≈85.1，p=1.8×10⁻³⁷，在“近独立块均值”的前提下，拒绝“均值无差”的原假设。
